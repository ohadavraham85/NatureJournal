# יומן טבע

אפליקציית PWA לדיווח תצפיות טבע — יונקים, פרפרים, פרחים וצמחים, זוחלים ודו-חיים, חרקים, פטריות ואחר.

- דיווח שמתחיל בתמונה: התאריך והמיקום נלקחים מנתוני התמונה (EXIF), ואם אין — מהשעה ומה-GPS של המכשיר.
- יומן ברשת תמונות עם חיפוש וסינון לפי קטגוריה.
- הכול נשמר במכשיר (IndexedDB) ועובד גם בלי קליטה; אפשר להתקין למסך הבית.

**כתובת:** https://ohadavraham85.github.io/NatureJournal/

## פיתוח

```bash
npm install
npm run dev      # http://localhost:8787
npm run build    # בדיקת טיפוסים + בנייה
```

כל דחיפה ל-`main` בונה, מסמנת גרסה (`v1.0.x`) ומפרסמת ל-GitHub Pages.
